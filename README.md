### 🛡️ Virtualised SOC Home Lab

**Status:** In progress

I'm developing a home lab to understand how security monitoring works across multiple systems and how endpoint activity can be collected for investigation.

**Environment includes:**
- Kali Linux — attacker-side testing environment.
- Ubuntu — host for the centralised Wazuh SIEM setup.
- Windows — endpoint generating security events.
- pfSense — virtualised firewall and network-security component.
- Windows event collection software — configured to forward endpoint logs to the SIEM.

**Current learning goals:**
- Complete and verify Windows log ingestion into Wazuh.
- Understand how endpoint events become searchable security data.
- Investigate events and learn to distinguish suspicious activity from normal behaviour.
- Develop and test detection rules with documented evidence.

*The lab is partially configured. End-to-end log ingestion and detection results will be documented as they are verified.*
